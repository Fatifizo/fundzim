# Stage 19 — Financial concurrency, load, failure and integrity validation

Status: **complete; awaiting acceptance; non-production; production BLOCKED.** Decision record:

[stage-19-final-report.md](stage-19-final-report.md). Next stage:
[STAGE-19-TO-STAGE-20](../stage-handover/STAGE-19-TO-STAGE-20.md).

Scope: prove — with reproducible evidence on simulators, TEST ledgers and disposable local infrastructure — that
concurrent and interrupted financial operations cannot create duplicate effects, lose entries, corrupt reservations,
bypass approvals or produce misleading reconciliation results; fix what does not hold. No live donation, payout,
settlement posting, provider credential or production deployment is involved; no gate was opened.

## Running the Stage 19 evidence

All commands from the repository root, with `.env` loaded (`set -a; . ./.env; set +a`) and under the stack lock
(`flock /tmp/claude-1000/fundzim-stack.lock …`), against the local compose stack only.

```bash
# deterministic concurrency, idempotency and fault tests (part of the normal integration suite and CI)
go test -tags integration -count=1 -run 'TestFinancial' -v ./tests/integration/

# worker crash (opt-in: kills the local worker)
FUNDZIM_IT_WORKER_KILL_CMD='docker compose kill fundzim-worker' FUNDZIM_IT_WORKER_START_CMD='docker compose up -d fundzim-worker' \
  go test -tags integration -count=1 -run TestFinancialWorkerCrashMidFlight -v ./tests/integration/

# load tiers and endurance (opt-in)
FUNDZIM_IT_S19_LOAD=1 FUNDZIM_IT_S19_TIERS=1,4,8,16 FUNDZIM_IT_S19_TIER_DURATION=3m FUNDZIM_IT_S19_ENDURANCE=30m \
  FUNDZIM_PERF_OUT=/tmp/s19 go test -tags integration -count=1 -timeout 120m -run TestFinancialLoad -v ./tests/integration/

# ledger volume tiers: a scratch database whose name contains fundzim_perf (never the development ledger)
sed 's/fundzim_perf/fundzim_perf_s19b/g' tests/perf/createdb.sql | docker compose exec -T fundzim-postgres psql -U postgres -d postgres
DATABASE_MIGRATION_URL=…/fundzim_perf_s19b?… go run ./apps/api/cmd/fundzimctl migrate up
FUNDZIM_PERF_LEDGER_URL=…fundzim_ledger…/fundzim_perf_s19b?… FUNDZIM_PERF_SCALES=1000,10000,100000 \
  go test -tags perf -count=1 -timeout 120m -run '^TestLedgerPerf$' -v ./tests/perf/ledger/
```

The barrier and fault tests need `POSTGRES_SUPERUSER_PASSWORD` (generated by `scripts/dev-env-init.sh`) only to
terminate backends blocked by their own row lock.
